# Ready Prompts — BasetaTube 2D Game Studio v2

## 1) Target Look Mode — شكل اللعبة النهائي

استخدم مهارة basetatube-2d-game-studio.

الوضع: Target Look Mode

اصنع 4 أوامر صور لشكل لعبة نهائي متخيل، 16:9، للعبة 2D بالعرض على طريقة ماريو.

فكرة اللعبة:
ولد مصري صغير يجري ويقفز في عالم يجمع بين شوارع وحواري القاهرة الشعبية والمعابد الفرعونية. اللاعب يجمع عملات ذهبية على شكل عنخ، يقفز فوق العقبات، يواجه جعران كعدو، تظهر قطة فرعونية، وتوجد مومياء لطيفة وBoss صغير في النهاية.

الاتجاه البصري:
ستايل 2D كرتوني مصقول، جودة لعبة موبايل حديثة، منظور جانبي، شوارع القاهرة القديمة، لافتات عربية بسيطة، محلات شعبية، أقمشة معلقة، مباني دافئة، قباب ومآذن بعيدة، أعمدة ومعابد وتماثيل فرعونية، إضاءة غروب ذهبية، توهج تركواز، عمق parallax، واجهة عربية واضحة.

مطلوب في كل صورة:
- لقطة gameplay أفقية 16:9
- HUD عربي فيه النقاط والعملات والمستوى والقلوب
- منصات حجرية قابلة للعب
- عملات ذهبية
- اللاعب في وضع حركة أو قفز
- عدو واحد على الأقل
- بدون شعارات أو شخصيات محمية بحقوق

اكتب الأوامر بالإنجليزية والشرح بالعربية.

## 2) Asset Prompt Mode — أوامر أصول اللعبة

استخدم مهارة basetatube-2d-game-studio.

الوضع: Asset Prompt Mode

أنشئ حزمة أوامر لتوليد أصول لعبة 2D بالعرض على طريقة ماريو.

فكرة اللعبة:
ولد مصري صغير يجري ويقفز في عالم يجمع بين شوارع وحواري القاهرة الشعبية والمعابد الفرعونية. يبدأ اللاعب في حارة مصرية ضيقة فيها محلات قديمة، جدران شعبية، لافتات عربية بسيطة، عربات، وإضاءة دافئة. بعد ذلك يدخل إلى منطقة فرعونية فيها أعمدة، تماثيل، ممرات معابد، نقوش، إضاءة ذهبية، ولمسات تركواز.

عناصر اللعبة:
- بطل اللعبة: ولد مصري صغير
- شخصية مساعدة أو عنصر بصري: قطة فرعونية لطيفة
- عدو واحد: جعران فرعوني
- مومياء لطيفة
- Power-up واحد
- Boss صغير في النهاية
- عملات ذهبية على شكل عنخ
- عقبات يقفز فوقها اللاعب

الستايل المطلوب:
ستايل 2D كرتوني مصقول، منظور جانبي side-scrolling، ألوان زاهية، جودة لعبة موبايل حديثة، تفاصيل مصرية واضحة، مزيج بين حواري القاهرة والمعابد الفرعونية، ألوان دافئة مع ذهبي ورملي وبرتقالي وأحمر ولمسات تركواز، أشكال واضحة، بدون شخصيات محمية بحقوق، بدون شعارات، وبدون نصوص عشوائية.

مهم:
- اكتب أوامر الصور بالإنجليزية
- اجعل الشرح والتنظيم بالعربية
- راعِ أن واجهة اللعبة ستكون بالعربية
- ركّز على الأصول الأساسية فقط
- أعطني أسماء ملفات منظمة لكل أصل
- للأصول المعزولة اطلب PNG بخلفية شفافة حقيقية مع alpha channel وبدون checkerboard
- للواجهة العربية الأفضل توليد UI panels بدون نصوص كثيرة وإضافة النص العربي داخل Phaser

## 3) Phaser Build Mode — بناء اللعبة

استخدم مهارة basetatube-2d-game-studio.

الوضع: Phaser Build Mode

لقد قمت بتوليد أصول اللعبة وحفظتها داخل المجلدات المقترحة.

ابنِ لعبة Phaser 3 قابلة للتشغيل في المتصفح باستخدام هذه الأصول.

عنوان اللعبة:
مغامرة القاهرة الفرعونية

نوع اللعبة:
لعبة 2D بالعرض على طريقة ماريو.

فكرة اللعبة:
اللاعب يتحكم في ولد مصري صغير يجري ويقفز داخل عالم يجمع بين شوارع وحواري القاهرة الشعبية والمعابد الفرعونية. يجمع العملات، يتفادى العقبات، يواجه عدوًا واحدًا، يحصل على Power-up واحد، ثم يواجه Boss صغير في نهاية المستوى الثاني.

المتطلبات الأساسية:
- Phaser 3
- لعبة تعمل في المتصفح
- حركة يمين ويسار
- قفز وجاذبية
- كاميرا جانبية side-scrolling
- خلفيات Parallax
- عملات مع نظام Score
- عدو واحد
- Power-up واحد
- Boss صغير في نهاية Level 2
- على الأقل مستويان
- Start screen
- Game over screen
- Level complete screen
- Restart button
- Next level button
- نظام Levels سهل التعديل باستخدام LEVELS array

نظام النقاط:
- جمع عملة = 10 نقاط
- هزيمة عدو = 50 نقطة
- جمع Power-up = 100 نقطة
- هزيمة Boss = 500 نقطة
- إنهاء المستوى = 250 نقطة إضافية

واجهة اللعبة:
اجعل واجهة اللعبة بالعربية، واستخدم نصوص قصيرة وواضحة مثل:
- ابدأ
- إيقاف
- إعادة
- النقاط
- العملات
- المستوى
- التالي
- انتهت اللعبة
- اكتمل المستوى

مهم:
- اجعل الكود بسيطًا ومنظمًا
- اجعل اللعبة سهلة الشرح والتعديل
- ضع constants في أعلى الكود لتعديل أبعاد sprite sheets بسهولة
- اجعل إضافة مستويات جديدة سهلة من خلال LEVELS array
- لو أي asset غير موجود، استخدم placeholder مؤقت بنفس الاسم
- استخدم النص العربي داخل Phaser كلما أمكن بدل حرقه داخل صور الواجهة
