# BasetaTube 2D Game Studio v2

Skill for creating a 2D side-scrolling Mario-style platformer workflow:

1. Target Look Mode: create polished gameplay screenshot prompts.
2. Asset Prompt Mode: create game-ready asset image prompts.
3. Phaser Build Mode: build a Phaser 3 prototype with score, levels, enemy, power-up, and boss.

Optimized visual direction:
Cairo alleys + Pharaonic temple + Arabic UI + polished 2D cartoon mobile game look.

Important production note:
The target gameplay screenshot is only a visual reference. For an actual game, generate separate assets: sprites, tileset, backgrounds, UI, collectibles, and power-ups.
